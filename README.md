# Student Performance Prediction using Machine Learning

A medium-level ML portfolio project that predicts a student's final academic score from academic and behavioral features.

## Features
- Data preprocessing
- Exploratory analysis foundation
- Feature-based regression
- Linear Regression, Random Forest and Gradient Boosting
- MAE, RMSE and R² evaluation
- Automatic best-model selection
- Model saving/loading
- Actual-vs-predicted visualization

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Scikit-learn, Joblib

## Run
```bash
pip install -r requirements.txt
python src/train_model.py
python src/predict.py
```

The included dataset is synthetic and created for learning/portfolio demonstration, not real student records.

## GitHub Description
Machine learning project for predicting student performance using regression models, data preprocessing, model comparison, evaluation metrics, and prediction.
